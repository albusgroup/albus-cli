# Security Policy

## Supported versions

During the MVP, only the latest published `albus-cli` version receives security
updates. Upgrade to the newest release before reporting a vulnerability unless
the issue prevents doing so.

## Report a vulnerability

Do not disclose security vulnerabilities in a public issue or pull request.
Use GitHub's
[private vulnerability report](https://github.com/albusgroup/albus-cli/security/advisories/new)
to contact the maintainers.

Include the affected CLI version, impact, reproduction steps, and any suggested
mitigation. Remove API tokens, organization keys, secret values, personal data,
and unrelated customer data from the report.

The maintainers will use the private advisory to acknowledge the report,
coordinate investigation and remediation, and discuss disclosure timing.
